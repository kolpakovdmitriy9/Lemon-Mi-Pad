# Lemon vs Kenji-NX: кандидаты на скорость (анализ по коду)

Статус: только анализ кода, без профайлинга на устройстве. Ни один пункт не измерен.

## Что Lemon делает ради скорости (и чего нет в Kenji-NX по умолчанию)

| Область | Lemon (C++/Vulkan) | Kenji-NX (C#/Ryujinx) | Комментарий |
|---|---|---|---|
| Таймер GPU | `fast_gpu_time` = Boost | по умолчанию без Boost | Игра «думает», что GPU быстрее; влияет на тайминги |
| Режим GPU | Accurate по умолчанию | (нужна проверка) | Accurate медленнее, но без мерцания |
| Декодирование ASTC | на GPU | на GPU (проверить) | Совпадает по смыслу |
| Перекодирование BCn | BCn→ASTC/EAC, если нет нативного BCn | только если нет BCn | На Adreno нативный BCn, пункт не нужен |
| Кэш шейдеров | конвейеры + трансляция fragment-шейдеров ≥30 мс | дисковый кэш шейдеров | Lemon кэширует трансляции, которые дорого считать |
| Вершинные буферы | `use_optimized_vertex_buffers` (выкл. по умолчанию) | (нет эквивалента) | Требует драйвер Mesa 26+ |
| Выгрузка памяти | `gpu_unswizzle_enabled` (выкл.), размеры Large/Medium | (нет эквивалента в той же форме) | Кандидат на разгрузку CPU |
| Инвалидация памяти | `skip_cpu_inner_invalidation` (выкл. по умолчанию) | (нет) | Опасно для текстур: может дать пустые копии |
| Пути для Adreno | флаги по driver_id (Qualcomm/Turnip), обход gs side effects | общий путь | Если упрощать путь, можно вернуть баг |

## Что не стоит переносить без проверки
- `skip_cpu_inner_invalidation`: включение может вернуть ошибку с текстурами, которую мы уже ловили.
- Обходы для Adreno по `driver_id`: завязаны на драйвер, на другом железе могут сломать картинку.
- `fast_gpu_time`: меняет тайминги игры, возможны побочные эффекты в логике.
